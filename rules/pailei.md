# 排雷规则

本文件是**你个人**的判定规则，工具里所有 PASS/WARN/FAIL 的唯一裁决来源。
阈值直接改这里，改完重跑即生效，不需要动代码。

格式约定（解析器遇到未知字段会直接报错，不会静默忽略）：

- `field`  参与判定的派生指标名，取自 `src/fw/derive.py`
- `check`  方向：`lte`（越小越好）/ `gte`（越大越好）/ `eq`（必须命中 allow）
- `warn` / `fail`  阈值，单位随 field 定义
- `allow`  check=eq 时的许可取值列表，逗号分隔
- `layer`  0 = 一票否决层，命中 FAIL 直接排除
- `learn`  注释面板显示的学习要点：**解释为什么这条存在**，不是重复阈值
- `drill`  该去年报哪里核对，格式「报表/章节 · 科目名」

> 判定权归代码，解释权归知识层。`rules/notes.md` 里的教材参考值只能补充视角，
> 不能推翻这里的任何一条。

## R0.1 审计意见非标准
- layer: 0
- field: audit_opinion
- check: eq
- allow: 标准无保留意见
- learn: 审计意见是整份年报可信度的地基。一旦落到「保留」「无法表示意见」「否定」，后面所有比率都建立在可能失真的数字上，再精算也没有意义。「非标」还包含一种常见情形：标准无保留但带强调事项段——它不否定报表，但提示存在重大不确定性，值得单独看一眼。
- drill: 审计报告全文 · 审计意见段

## R0.2 扣非净利润与归母净利背离
- layer: 0
- field: deducted_gap_ratio
- check: gte
- warn: 0.70
- fail: 0.50
- learn: 扣非归母 / 归母 < 0.5，意味着一半以上利润来自一次性项目（卖资产、政府补助、公允价值变动、投资收益）。这类利润不产生持续现金流，也不代表主业竞争力，却会同样推高 EPS 和 ROE。连续两年低于 0.7 就该怀疑主业的真实盈利能力。
- drill: 利润表 · 归属于母公司所有者的净利润 / 财务报表附注 · 非经常性损益明细表

## R1.1 商誉占归母净资产比
- field: goodwill_ratio
- check: lte
- warn: 0.30
- fail: 0.50
- learn: 商誉是并购溢价在账面上的残留，本身不产生现金流，只在被并购方业绩达标时才「值」这个价。它每年不做摊销、只做减值测试，所以业绩不达标的部分会攒着，到某一年一次性减值直接砸穿利润。商誉占净资产过半的公司，账面净资产的可信度要整体打折。
- drill: 资产负债表 · 商誉 / 附注 · 非同一控制下企业合并、商誉减值测试

## R1.2 有息负债率
- field: interest_bearing_debt_ratio
- check: lte
- warn: 0.40
- fail: 0.60
- learn: 只看资产负债率会被大量无息负债误导——预收款、应付账款、合同负债这些是占用上下游的钱，不但没有利息压力，反而说明议价能力强。真正要盯的是要付利息、要还本金的那部分：短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券。国内两个开源实现都只用了长期借款一项，对A股会系统性低估杠杆水平。
- drill: 资产负债表 · 短期借款、一年内到期的非流动负债、长期借款、应付债券

## R1.3 经营现金流覆盖归母净利
- field: ocf_to_profit
- check: gte
- warn: 0.80
- fail: 0.50
- learn: 长期低于 1 说明利润没能收到钱，差额躺在应收账款和存货里。一次两次的背离可能是节奏问题（大额订单跨期回款），连续多年背离就要看应收增速是否显著高于营收增速。这是F-Score 应计项规则的A股加强版——F-Score 只看当年二值，趋势信息在多年覆盖比里。
- drill: 现金流量表 · 经营活动产生的现金流量净额 / 利润表 · 归属于母公司所有者的净利润

## R2.1 应收账款增速相对营收增速
- field: receivable_revenue_gap
- check: lte
- warn: 0.15
- fail: 0.30
- learn: 应收增速远超营收增速，通常只有两种解释：靠放宽信用政策换销量，或者收入确认口径变了。前者会透支未来的现金流，后者需要立刻去看收入确认的具体政策有没有变更。营收高增长同时应收也同步高增的公司，增长质量要单独评估。
- drill: 资产负债表 · 应收账款 / 利润表 · 营业总收入 / 附注 · 重要会计政策和会计估计变更

## R2.2 存货增速相对营收增速
- field: inventory_revenue_gap
- check: lte
- warn: 0.20
- fail: 0.35
- learn: 存货堆积有两种完全不同的成因，必须分开看：一种是主动备货（旺季前、原材料预期涨价、产能爬坡），另一种是产品滞销。区分方法不是看存货本身，而是看它是否伴随毛利率下滑和周转率下降——三者同时出现，是滞销而非备货。
- drill: 资产负债表 · 存货 / 附注 · 存货跌价准备

## R3.1 毛利率行业背离
- field: gross_margin
- check: gte
- warn: 0.10
- learn: 毛利率低于 10% 的公司，靠规模效应翻身的空间很小，一旦上游涨价或需求走弱就滑到亏损线以下。这条阈值不区分行业，所以对制造业偏松、对软件和快消偏严——把它当绝对门槛看，行业内的相对位置要靠同业对比页判断。
- drill: 利润表 · 营业总收入、营业成本

## R3.2 资产负债率（账面口径）
- field: debt_to_assets
- check: lte
- warn: 0.70
- fail: 0.85
- learn: 这是总口径的粗筛，用途是拦住那些连账面资产负债率都已经危险的公司。它对金融地产会误报——银行保险的高负债是业务本身，不应当作风险信号。判断金融业时以有息负债率（R1.2）和流动性指标为准，本条仅作参考。
- drill: 资产负债表 · 资产总计、负债合计

## R4.1 权益乘数异常放大
- field: equity_multiplier
- check: lte
- warn: 3.5
- fail: 5.0
- learn: ROE 有三个来源：赚得多（净利率）、转得快（周转率）、扛得重（权益乘数）。乘数超过 3.5，意味着高 ROE 里杠杆的贡献占比很大——同样的资产收益率，去杠杆之后 ROE 会成比例缩水。看杜邦归因页哪个因子主导 ROE 变动，比看 ROE 高低本身信息量大得多。
- drill: 资产负债表 · 实收资本（股本）、归属于母公司所有者权益合计
